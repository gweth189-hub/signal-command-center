# ⚡ SIGNAL XERLORT

### Learn. Experiment. Defend. Build.

**SIGNAL XERLORT** is an interactive, beginner-friendly technology learning hub that combines coding challenges, cybersecurity simulations, engineering missions, and mini-games in one web application.

It is designed to help students and aspiring tech enthusiasts develop practical skills, strengthen their problem-solving abilities, and explore cybersecurity in a safe, engaging environment.

## 🎯 Purpose

Learning programming and cybersecurity can feel difficult when you only study theory. SIGNAL XERLORT makes learning more interactive by giving users challenges to solve, tools to experiment with, and missions to complete.

The goal is to make technology education more accessible, engaging, and practical for beginners.

## ✨ Features

- 🧠 **Smart Offline Assistant** — Rule-based responses to commands and learning requests without requiring an AI API.
- 💻 **Coding Challenges** — Practise JavaScript debugging and explore programming concepts.
- 🛡️ **Cybersecurity Training** — Investigate fictional logs, identify suspicious activity, and practise defensive incident response.
- 🌐 **Simulated Network Lab** — Explore an interactive network map and learn to recognise unusual activity.
- 🔧 **Tech Toolkit** — Experiment with Base64, Caesar cipher, binary, and hexadecimal conversions.
- 🎯 **Mission Board** — Complete tasks, earn XP, level up, and unlock achievements.
- ⏱️ **Focus Timer** — Organise study sessions and build productive learning habits.
- 🎮 **Mini-Games** — Enjoy reflex challenges and a soccer penalty shootout.
- 🏆 **Progress Tracking** — Track achievements, missions, and learning activity.
- 💾 **Progress Backup** — Export and import progress using JSON files.
- 🔊 **Voice Output** — Hear supported assistant responses through browser speech synthesis.

## 🚀 Why SIGNAL XERLORT?

- Brings several technology learning activities into one place.
- Encourages hands-on experimentation instead of theory alone.
- Makes cybersecurity concepts easier to explore through safe simulations.
- Uses game-like rewards to encourage continued practice.
- Works as a lightweight browser-based project without a required backend.
- Is designed to be hosted on GitHub Pages.

## 🛠️ Built With

## 🔐 Safe Learning

SIGNAL XERLORT focuses on educational cybersecurity simulations. Its network lab and incident-response activities use fictional scenarios to help beginners understand defensive security concepts without targeting real systems.

## 🌱 Future Vision

The project can grow to include more coding challenges, additional defensive cybersecurity scenarios, expanded engineering missions, improved accessibility, and more ways for learners to track their progress.

## 👨‍💻 Project Goal

SIGNAL XERLORT is a learning-focused project built around one idea: **technology should be something beginners can explore, practise, and understand—not just read about.**
